# 🚀 Workify — Task Management Board

**Workify** is a modern, visually appealing task management web application designed to help individuals and teams organize their work efficiently. It provides a clean, board-based interface to create tasks, track progress, and manage tasks from start to completion.

This project was developed collaboratively as a **pre-assigned task before joining an internship**, providing an opportunity to demonstrate teamwork, practical development skills, and the ability to build a functional web application.

🔗 **Live Demo:** [https://workify-7467.web.app/](<https://workify-7467.web.app/>)

## ✨ Features

- 🔐 **User Authentication** — Sign in and create an account to access your workspace.
- 📋 **Task Management Board** — Organize tasks using a visual board layout.
- ➕ **Create Tasks** — Add tasks with a title and detailed description.
- 👥 **Task Assignment** — Assign tasks to colleagues using their email addresses.
- 🔗 **Reference Links** — Attach relevant URLs to tasks.
- 📎 **File Attachments** — Add files to provide additional context for tasks.
- 🔄 **Track Task Progress** — Move tasks between different workflow stages.
- 🗂️ **Three Task Stages** — Manage tasks across:
  - **To Do**
  - **In Progress**
  - **Completed**
- 🔍 **Task Details Drawer** — View task descriptions, metadata, and available actions.
- 🗑️ **Delete Tasks** — Remove tasks when they are no longer needed.
- 📊 **Task Counters** — See the number of tasks in each workflow stage.
- 🎨 **Modern UI** — Enjoy a clean interface with custom styling, elegant typography, and a visually appealing design.

## 🖥️ Preview

Workify features a four-column workspace consisting of a task creation panel and three task status columns.

| Section | Description |
| --- | --- |
| New Task | Create tasks and configure additional options. |
| To Do | Keep track of tasks waiting to be started. |
| In Progress | Monitor tasks currently being worked on. |
| Completed | View finished tasks. |

## 🚀 Getting Started

Follow these steps to run Workify locally.

### 1\. Clone the Repository

```
git clone https://github.com/Pratham00007/Workify.git
```

### 2\. Navigate to the Project Directory

```
cd Workify
```

### 3\. Configure Firebase

Set up your own Firebase project and configure the required credentials and services according to your application's implementation.

**Important:** Never commit private credentials, service account keys, or other secrets to a public repository. Use appropriate configuration and security rules for your Firebase services.

### 4\. Run the Application

Open the login page in your browser or use the **Live Server** extension in Visual Studio Code.
